# Sierpiński Triangle: RGB Shader Convergence

This updated and enhanced project demonstrates shader colour convergence through a Sierpiński triangle. Each vertex stores an RGB colour, which the vertex shader passes to the fragment shader. OpenGL then smoothly interpolates those values across every triangle. The red, green, and blue sections blend at their shared vertices, producing yellow, magenta, and cyan transition points. This creates a continuous gradient without switching fragment shaders for each section.
